## Technologies Utilisées

Ce portfolio a été réalisé avec les technologies fondamentales du web :

- **HTML5** : Structure des pages web
- **CSS3 / SASS** : Mise en forme et responsive design
- **JavaScript (ES6+)** : Dynamisme du site et chargement des données
- **JSON** : Stockage et structuration des contenus du site
